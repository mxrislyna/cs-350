The goal of this project was to build an embedded system that could read room temperature using an AHT20 sensor, show heating and cooling states using LEDs, and respond to button presses. The system also displayed real-time information on a 16x2 LCD and used a UART serial connection to simulate sending data to the cloud.

One thing I did well was organizing the system using a state machine and threading. I learned that running the LED loops in a separate thread allowed the main program to respond to button presses without being delayed by timing pauses. However, I could improve by checking for hardware issues earlier. For example, I had to adjust the LCD potentiometer to get the display working properly, and the ribbon cable made it harder to access some GPIO pins. These experiences helped me understand how important it is to check the hardware connections along with the code.

Throughout this course, I gained experience with state machines, the Python gpiozero library, and troubleshooting hardware problems. I also learned how to turn project requirements into working code while considering limits such as cost, power use, and hardware capabilities. To make the project easier to maintain, I organized the code around a Moore state machine and added comments to explain important parts of the program, especially the use of threading. This should make it easier to understand and update the code in the future.
